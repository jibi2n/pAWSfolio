# pAWSfolio

A blog-style app built as my submission for the **AWS Builders - UST** developer assessment.

The design is inspired by the [AWS Builders - UST website](https://www.aws-ust.org).

<!-- Screenshot / demo GIF goes here -->

## The Assessment

Build a blog-style application with the following features:

| #   | Feature              | Description                                                                     |
| --- | -------------------- | ------------------------------------------------------------------------------- |
| 1   | **Create a Post**    | Users can create their own post. Each post must have a title and a description. |
| 2   | **View All Posts**   | Shows all the posts that were created.                                          |
| 3   | **View Single Post** | Users can view a single post, along with all of its comments.                   |
| 4   | **Add Comment**      | Users can add a comment to a post.                                              |
| 5   | **Delete Comment**   | Users can delete comments made on their post.                                   |

**Rules:** Any resources or frameworks are allowed (React, jQuery, Bootstrap, etc.), but **no templates**, not even for components (headers, footers, shadcn, etc.).
